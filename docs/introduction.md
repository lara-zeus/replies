## Introduction
@zeus Replies, is a bookmark manager for your filament resources.

**[Demo](https://demo.larazeus.com/admin/bookmarks) · [Github](https://github.com/lara-zeus/replies) · [Discord](https://discord.com/channels/883083792112300104/1282762546134384640)**

## Features

- 🔥 Add any resources to bookmark.
- 🔥 easy access to the bookmark list from the top bar
- 🔥 included widget
